About CineVault

A tidy home for everything you love to watch

CineVault was built as a compact demo for the eBEYONDS web developer evaluation. It combines a hand-built responsive front end with a live TV/movie search connected to the TVMaze API, plus a small PHP backend that validates and stores contact requests and sends confirmation email.

  • Responsive across mobile, tablet and desktop
  • Accessible, keyboard-friendly navigation
  • Live search with an editable favorites grid
